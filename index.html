Parcel Analytics Warehouse

PostgreSQL · CI green

PostgreSQL 16 · Docker · GitHub Actions · 12.4M rows

A star schema for parcel logistics built at a size where the decisions matter — 2 million shipments and 10.4 million scan events, range-partitioned monthly. Every index justified by a before/after measurement rather than a habit, including one query where indexing changed nothing because partition pruning had already done the work.
